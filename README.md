# 黎er

全栈开发，主 Python。后端 Flask / SQLite，前端 Vue 3 + Vite 构建并自动部署，两边都自己写、也自己测。

## 在做的

- **[EnglishOS](https://github.com/qwqianli/EnglishOS)** —— 用真实外刊、播客与视频做精读、精听、口语评测与间隔复习，全程在本机运行，学习数据不出机器。
- **[data-struct-lab](https://github.com/qwqianli/data-struct-lab)** —— Vue 3 + Vite 的数据结构可视化实验台，30 个组件；CI 先跑 330 条引擎断言再构建，产物自动发布到 GitHub Pages。
- **[bilibili-test](https://github.com/qwqianli/bilibili-test)** —— 给 B 站数据爬取与分析项目配套的 pytest 工程，覆盖接口、数据与边界场景，接了 CI。
